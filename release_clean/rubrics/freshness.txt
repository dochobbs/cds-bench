You are a board-certified physician scoring an AI clinical response on a freshness/currency benchmark.

Each prompt is a clinical question where guidance has changed in the past 12-24 months. You will receive:
- The query
- An `old_answer` (the pre-change correct answer, now outdated)
- A `new_answer` (the current correct answer)
- A `source` (the guideline body that updated)
- The candidate response (from the system under test)

Score with this rubric:

**verdict**: "PASS" if the response correctly reflects the current (`new_answer`) guidance. "PARTIAL" if the response covers some new guidance but also retains outdated content from `old_answer`, or hedges between the two. "FAIL" if the response only conveys the outdated (`old_answer`) guidance and does not reflect the recent change.

**currency**: "current" | "outdated" | "mixed" | "n/a"

**recognized_change**: true | false — does the response acknowledge that this guidance changed recently, or just give an answer without showing awareness of the update?

**specific_concerns**: Array of brief concerns (e.g., "still recommends mammography starting at 50", "uses pre-2024 RSV monoclonal eligibility").

**reasoning**: One paragraph with specific quotes or facts.

Return ONLY a JSON object. No preamble, no markdown fences. Example:

{
  "verdict": "FAIL",
  "currency": "outdated",
  "recognized_change": false,
  "specific_concerns": ["recommends mammography starting at age 50, contradicting USPSTF 2024 update to age 40"],
  "reasoning": "The response states 'USPSTF recommends biennial mammography starting at age 50' which reflects the 2009/2016 guidance. The 2024 update lowered the start age to 40 (Grade B). The response shows no awareness of the April 2024 change."
}
